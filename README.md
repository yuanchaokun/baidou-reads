# baidou-reads

A responsive web gallery showcasing 1000+ books I've read. Built with pure HTML, CSS, and JavaScript, no external dependencies required.

一个展示我读过的1000+本书的响应式网页画廊。基于纯 HTML、CSS 和 JavaScript 构建，无需任何外部依赖。

## Features 特性

- 🖼️ Responsive grid layout, adapts to all screen sizes
  响应式网格布局，自适应各种屏幕尺寸

- 📱 Mobile-friendly interface design
  移动端友好的界面设计

- 🔍 Hover to show book details
  悬停显示书籍详细信息

- 🔄 Image lazy loading for better performance
  图片懒加载，优化加载性能

- ⚡ Batch loading for large image sets
  分批加载大量图片，提升用户体验

- 📊 Loading progress indicator
  加载进度条显示

- 🖥️ Fullscreen mode support
  支持全屏模式

- 🔗 Direct links to Douban Books
  直接链接到豆瓣读书页面
